# Security policy

cuentalibre holds tax IDs, invoices and bank details, so security reports are taken seriously.

## Reporting a vulnerability

Don't open a public issue. Report it privately through GitHub: **Security › [Report a vulnerability](https://github.com/cuentalibre-app/cuentalibre/security/advisories/new)**.

Include what an attacker can do, the steps to reproduce it and the affected version or commit. You'll get an answer within a few days, and you'll be credited in the advisory unless you prefer not to be.

## Supported versions

Fixes go into the latest release. If you self-host, keep up with the [releases](https://github.com/cuentalibre-app/cuentalibre/releases).

## Scope

The app, the API, the self-hosted Docker setup and the agent skill in `.agents/skills/` are in scope. Please don't test against other people's data on cuentalibre.es: use your own account or a local install.
